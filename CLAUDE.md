# Правила работы с репозиторием

## Сборка
- Сайт собирается в статику (`output: 'export'` в `next.config.mjs`). Не добавлять API routes, server actions, `next/image` с оптимизацией и прочее, что требует сервера Node.js, — в образе только nginx.
- Шрифты — локально через `@fontsource`, не через `next/font/google` (сборка не должна ходить в Google).
- Все тексты, контакты и цены — в `src/lib/site.ts`. Цены «от» пока средние по рынку, заказчик пришлёт реальные.

## Оформление
- Палитры p1–p5 — в `src/app/globals.css`, выбранная — `PALETTE` в `src/lib/site.ts`. Компоненты берут цвета только из CSS-переменных палитры.
- PNG от заказчика уже с прозрачностью — не «вырезать» фон.
- На вывеске Eurorepar и «Деталька» вместе; на сайте Eurorepar не упоминаем, фото фасада показываем целиком.
- `palette-variants.html` не удалять — к выбору палитры могут вернуться.

## Релиз = деплой
- Тег `vX.Y` собирает образ `ghcr.io/zalessky/detalka` (`latest` и `X.Y`); NAS ночью забирает `latest` (см. `docs/DSM.md`).
- Имя образа в `.github/workflows/docker-image.yml` — только `detalka`. Если поставить `sterx`, сборка перезапишет образ rolf64.
- Релизы выпускает владелец сам в интерфейсе GitHub (Release с новым тегом, Target — `main`). Claude Code тег не ставит.
- К релизу готовить: версия в `package.json` и `package-lock.json`, запись в `CHANGELOG.md`, `npm run build` проходит.
- Пока сайт не выпускается наружу — только тестовый стенд на NAS (`http://192.168.1.56:8081`).
