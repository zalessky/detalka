# Техцентр «Деталька» — лендинг

Одностраничный сайт техцентра «Деталька» (Энгельс, ул. 148-й Черниговской Дивизии, 26), домен detalka.info.
Next.js 14 со статической сборкой (`out/`), раздаётся nginx в Docker — так же, как сайт СТО ROLF (репозиторий SterX).

## Разработка

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # статика в out/
```

## Где что менять

| Что | Где |
| --- | --- |
| Телефон, адрес, MAX, Telegram, цены «от», список работ, отзывы | `src/lib/site.ts` |
| Ключ Web3Forms для заявок на sto@detalka.info | `src/lib/booking.ts` (`WEB3FORMS_KEY`) |
| Палитра (p1–p5) | `src/lib/site.ts` (`PALETTE`), цвета — `src/app/globals.css` |
| Фото | `public/images/photos/` (пока временные из 2ГИС, Яндекс Карт и канала VIBROCAR) |

### Палитры

Пять вариантов по визитке описаны в `src/app/globals.css` и показаны в `palette-variants.html` (открывается в браузере, графика внутри файла).
Сейчас выбран **p4 «Морской»**. Посмотреть другой вариант на живом сайте без пересборки: `https://detalka.info/?palette=p2`.

### Форма записи

Заявки уходят письмом на sto@detalka.info через Web3Forms. Пока ключ не задан, после отправки форма предлагает позвонить или написать в MAX.

## Релиз и деплой

Тег `vX.Y` запускает `.github/workflows/docker-image.yml`: образ `ghcr.io/zalessky/detalka` с тегами `latest` и `X.Y`.
Репозиторий приватный, поэтому образ тоже приватный: на сервере нужен `docker login ghcr.io` с токеном GitHub (право `read:packages`).

## Исходники оформления

- `*.png` в корне — исходники логотипа и свечи от заказчика (с прозрачностью);
- `ref/` — визитка и баннер вибростенда, по которым подобрана палитра;
- `palette-variants.html` — страница выбора палитры.
